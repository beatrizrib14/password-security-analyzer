🔐 Password Security Analyzer

Analisador de segurança de senhas desenvolvido em Python.

📌 Sobre o projeto

O Password Security Analyzer é uma aplicação desenvolvida em Python para avaliar características de composição de senhas e identificar critérios básicos de segurança.

O projeto tem como objetivo aplicar conceitos de programação ao contexto da Cibersegurança, explorando boas práticas relacionadas à criação e proteção de senhas.

🎯 Objetivos

* Avaliar a composição de senhas.
* Identificar características que contribuem para sua segurança.
* Verificar critérios básicos de complexidade.
* Aplicar conceitos de programação em um cenário de Segurança da Informação.

⚙️ Funcionalidades

* Verificação de comprimento mínimo de 12 caracteres.
* Identificação de letras maiúsculas e minúsculas.
* Verificação da presença de números.
* Identificação de caracteres especiais.
* Classificação da composição da senha.
* Entrada protegida, sem exibição da senha no terminal.

🛠️ Tecnologias utilizadas

* Python 3
* Biblioteca string
* Biblioteca getpass

⚠️ Limitações

A classificação considera exclusivamente os critérios implementados na aplicação. O resultado não representa uma auditoria completa de segurança, não verifica vazamentos de senhas e não garante resistência contra ataques.
